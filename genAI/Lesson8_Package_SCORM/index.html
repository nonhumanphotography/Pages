Welcome: Images Can Be Prompts Too

In Lesson 8, you move beyond text-only prompting. Your mission is to decide what a visual input should control, what the written prompt should control, and how much freedom the model should have.

Core learning question: What should the image input control, what should the written prompt control, and how much freedom should the model have to transform the reference?

Learning Objectives

  1. Explain the difference between text-to-image and image-to-image generation.
  2. Use sketches, wireframes, or low-detail visual inputs to guide image generation.
  3. Identify style, composition, color, subject, lighting, pose, and environment references.
  4. Understand the balance between fidelity and freedom.
  5. Write prompts that specify what the model should preserve, transform, and avoid.
  6. Use reference images responsibly without copying protected, personal, branded, or inappropriate material.
  7. Generate controlled interpretations from the same sketch or reference.
  8. Document the relationship between input image, prompt, settings, and final output.

Images as Prompts: From Text-to-Image to Image-to-Image

Text-to-image generation creates an image primarily from written language. Image-to-image generation adds a visual input: a sketch, photograph, wireframe, screenshot, design mockup, previous AI output, or collage. The prompt still matters, but the image gives the model a structural or visual starting point.

Key idea: Visual inputs reduce ambiguity. A rough sketch can communicate placement, scale, empty space, and composition more directly than a long written prompt.

Visual Inputs and What They Can Control

Not every visual input has the same function. A sketch may control composition, a wireframe may control layout, a photograph may control lighting or perspective, and a color reference may control mood.

Visual inputWhat it can controlRisk to manage
SketchPlacement, scale, rough pose, spatial structure.Too vague may be ignored; too detailed may restrict exploration.
WireframeLayout, hierarchy, negative space, aspect ratio.The model may fill reserved spaces with fake text or clutter.
PhotographPerspective, lighting, pose, environment, color mood.May copy subject matter or identity if not constrained.
Color referencePalette, temperature, contrast, atmosphere.The model may copy objects unless told to use color only.
Style referenceTexture, medium, realism level, visual language.Can become imitation of a living artist or protected visual identity.
Previous AI outputComposition, character attempt, style direction, draft to refine.Errors may be carried forward if not diagnosed.

References, Fidelity, and Creative Control

A reference image can guide style, composition, color, subject, lighting, pose, or environment. The key is to define the role clearly: a reference should mean “use this image for a specific kind of guidance,” not “copy this image.”

Reference prompt formula: Use the reference for [specific purpose]. Transform it into [desired result]. Preserve [stable elements]. Change [variable elements]. Avoid [copying/risk elements]. Style [visual language].

Fidelity vs Freedom Test

Decision feedback: High fidelity is not always better. Choose high fidelity when structure matters, balanced influence when both control and interpretation matter, and high freedom when exploration matters more than precision.
