Welcome: Prompt Engineer Mission

Lesson 4 turns prompt writing into a guided design practice. Your mission is to translate vague creative intention into visible, testable, and revisable instructions for an image-generation model.

Core learning question: What do I need to make explicit so that the model has a better chance of producing the image I intend?

Translate

Convert feelings and concepts into visible details.

Build

Use prompt components to create structured instructions.

Test

Change one variable at a time and document the result.

Learning Objectives

By the end of this lesson, you will be able to:

  1. Explain why vague prompts often produce vague, generic, or unpredictable images.
  2. Identify the main components of a strong visual prompt: subject, action, context, style, composition, lighting, camera language, mood, and technical details.
  3. Distinguish between human-oriented creative language and machine-oriented prompt language.
  4. Rewrite weak prompts into structured technical prompts that give the model clearer visual anchors.
  5. Use positive and negative prompts while recognizing that they do not guarantee absolute control.
  6. Explain implicit parameters, tokenization, word weighting, and prompt weighting.
  7. Apply controlled experimentation by changing only one prompt element at a time.
  8. Document prompt iterations and evaluate their visual effects as part of a design process.

Prompting Is Translation

A prompt is not simply a description of what you want. In AI image generation, a prompt translates human intention into machine-oriented visual instructions. You may begin with a feeling such as mysterious, professional, futuristic, or creative, but the model needs visible information: subject, place, objects, light, style, framing, and constraints.

Key idea: A prompt is not a wish, a magic formula, or a guarantee. It is a visual instruction system.

Human-Oriented vs Machine-Oriented Language

Human-oriented language is useful for creative thinking, but it often contains words that are too open for direct generation. Machine-oriented prompt language turns those words into subject, action, context, composition, style, lighting, camera language, mood, and constraints.

Anatomy of a Strong Visual Prompt

A strong visual prompt combines components that help the model connect the prompt to learned visual patterns. The structure does not guarantee a perfect output, but it creates clearer visual anchors and makes revision easier.

ComponentWhat it controlsExample language
SubjectThe main person, object, environment, or concept.A design student using an AI image-generation tool on a laptop.
ActionWhat the subject is doing.Reviewing generated images, sketching concepts, preparing a portrait session.
ContextWhere the scene takes place and what surrounds the subject.Inside a contemporary university design studio with cameras and printed sketches.
StyleThe visual language or medium.Realistic photography, editorial illustration, cinematic still, minimalist graphic design.
CompositionHow the image is framed and arranged.Wide shot, close-up, centered composition, rule of thirds, negative space.
LightingThe quality, direction, and mood of light.Soft daylight, dramatic side lighting, neon lighting, golden hour.
Camera languagePhotographic or cinematic framing details.Shallow depth of field, wide-angle lens, eye-level view, macro shot.
MoodThe emotional atmosphere of the image.Reflective, collaborative, mysterious, calm, energetic.
ConstraintsFormat or production requirements.Vertical poster background, no text, empty space for typography.

Prompt Formula: A Scaffold, Not a Prison

Prompt formula:
subject + action + context + composition + style + lighting + camera or technical details + mood + constraints

The formula helps you remember what can be specified, but it should not turn every prompt into a rigid list. A short prompt can be useful for exploration; a structured prompt is better when the image must serve a specific design, photography, or audiovisual task.

Guidance, Constraints, and Positive / Negative Prompts

Prompt engineering is not only about adding more description. Positive prompts describe what should appear. Negative prompts describe what should be avoided, where the tool supports them. Negative prompts can reduce problems, but they are not absolute prohibitions.

Implicit Parameters: What the Model Invents

Prompts contain implicit parameters: unstated choices that the model must fill in. A prompt such as “a successful designer in a studio” leaves age, gender, culture, clothing, discipline, studio type, camera angle, lighting, and visual style undefined.

Prompt to audit: “A successful designer in a studio.”

Tokenization, Prompt Weighting, and Emphasis

Some tools allow prompt weighting: increasing or decreasing the influence of specific words or phrases. Syntax depends on the platform, so learners should document exactly what tool and syntax they used.

Prompt Autopsy and Failure Diagnosis

A failed prompt should not lead immediately to random regeneration. Prompt autopsy asks what went wrong, why it happened, and which revision strategy is most appropriate. The solution may be a clearer prompt, a negative prompt, simplification, a different tool, or a workflow change.

Rule: Diagnose the failure before regenerating.
