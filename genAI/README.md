# AI Image Generation — sito web

Carica **il contenuto di questa cartella** nella radice del repository GitHub: `index.html`, `.nojekyll` e tutte le dieci cartelle `Lesson…_Package_SCORM` con i loro file.

In GitHub apri **Settings → Pages**, scegli **Deploy from a branch**, seleziona il branch `main` e la cartella **/ (root)**, quindi salva. Il sito sarà disponibile all'indirizzo indicato da GitHub Pages.

Per una prova locale apri `index.html` nel browser. La pagina principale contiene tutte le lezioni; in ciascuna lezione trovi indice, selettore e collegamenti precedente/successiva. Il layout utilizza tutta la larghezza disponibile e si adatta agli schermi piccoli.

Le risposte e i progressi vengono salvati nel browser per ciascuna lezione. GitHub Pages non fornisce il registro voti o il tracciamento centralizzato di un LMS. Le cartelle SCORM originali, fuori da questo sito, restano disponibili per l'importazione nel LMS.

Non caricare le altre cartelle del progetto, i documenti sorgente o gli archivi originali: per il sito basta il contenuto di questa cartella.
