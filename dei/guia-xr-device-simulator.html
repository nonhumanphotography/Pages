Cómo utilizar XR Device Simulator

Guía para controlar el HMD y los controladores XR con teclado y ratón, comprobar el agarre, probar la interacción mediante rayo y validar la teleportación sin utilizar un headset.

Unity 6XR Interaction Toolkit 3.1.x
PreparaciónCómo funcionaControlesAgarreRay InteractorTeleportaciónDiagnóstico

1. Preparar la escena

El simulador genera dispositivos XR virtuales. Para que funcione, el XR Origin debe leer la pose y los botones mediante Input System.

Importar el sample

Abrir Window → Package Manager → XR Interaction Toolkit → Samples. En XR Device Simulator, pulsar Import. Si ya aparece como importado, no repetir la operación.

Añadir el prefab a la escena

En Project → Assets → Samples → XR Interaction Toolkit → [versión instalada] → XR Device Simulator → XR Device Simulator, localizar XR Device Simulator.prefab y arrastrarlo a Hierarchy. Debe existir una sola instancia.

Comprobar las Input Actions

Seleccionar el prefab en Hierarchy. En Inspector, confirmar que sus campos de acciones tienen referencias asignadas. En el GameObject raíz XR Origin (XR Rig), comprobar Input Action Manager → Action Assets → XRI Default Input Actions.

Dar foco a Game

Pulsar Play y hacer clic una vez dentro de la ventana Game. El teclado y el ratón no controlarán el simulador si otra ventana conserva el foco.

Atención: XRI 3.1 también incluye el nuevo XR Interaction Simulator. Este recurso describe específicamente el prefab original XR Device Simulator. No mezclar ambos simuladores en la misma escena.

2. Entender el modelo de control

Antes de mover o pulsar un botón hay que indicar qué dispositivo se está manipulando. Después, el ratón mueve o rota ese dispositivo y las teclas simulan sus controles.

1. Elegir dispositivo→2. Elegir Translate o Rotate→3. Colocarlo→4. Activar Grip, Trigger o joystick

Control temporal

Mantener Left Shift para la mano izquierda, Space para la derecha o Mouse 2 para el HMD. Al soltar, deja de manipularse el dispositivo.

Control con Toggle

Pulsar T para dejar seleccionada la mano izquierda o Y para la derecha. Tab recorre Left Controller, Right Controller y Head. Esc detiene todas las manipulaciones.

4. Probar interacción directa y agarre

Seleccionar una mano

Pulsar T para la izquierda o Y para la derecha. Mover el ratón y usar la rueda hasta colocar el controlador junto al objeto.

Entrar en el volumen del Direct Interactor

Acercar el controlador hasta que el Sphere Collider de Direct Interactor solape el Collider del objeto. El objeto debe tener Rigidbody y XR Grab Interactable.

Agarrar y soltar

Mantener G para simular Grip. Mover o rotar la mano y comprobar que el objeto la sigue. Soltar G y verificar que el objeto queda libre.

Prueba superada: el objeto se resalta al acercar la mano, queda seleccionado mientras se mantiene G y responde al movimiento del controlador.

5. Probar Ray Interactor

  1. Seleccionar una mano con T o Y.
  2. Pulsar R para entrar en Rotate y orientar el controlador hacia un objeto lejano. Pulsar otra vez R para volver a Translate si hace falta recolocarlo.
  3. Confirmar que aparece la línea de Ray Interactor y que cambia su estado visual al detectar un objeto compatible.
  4. Mantener Mouse 1 para simular Trigger y ejecutar la acción Select configurada.
  5. Mover la mano manteniendo el gatillo para comprobar la manipulación a distancia; soltar para liberar el objeto.
Si aparece el rayo pero no selecciona: comprobar que Ray Interactor → Interaction Layer Mask y XR Grab Interactable → Interaction Layer Mask comparten al menos una capa, normalmente Default.

6. Probar teleportación

Los Starter Assets de XRI 3.x utilizan un Teleport Interactor independiente. Su activación suele estar vinculada al Primary 2D Axis, pero debe verificarse en el asset de acciones del proyecto.

Comprobar la configuración

Antes de pulsar Play, confirmar que Teleport Interactor → Interaction Layer Mask = Teleport, que Room_Floor → Teleportation Area → Interaction Layer Mask = Teleport y que el XR Origin contiene Teleportation Provider.

Seleccionar el controlador

En Play Mode, pulsar T o Y. Orientar la mano hacia el suelo usando R y el ratón.

Activar el joystick simulado

Pulsar 1 para dirigir el Primary 2D Axis con el teclado. Mantener W para empujar el joystick hacia delante. Si los Starter Assets conservan sus bindings, aparecerá el arco del Teleport Interactor.

Confirmar el destino

Apuntar a una posición válida de Room_Floor y soltar W. El XR Origin debe desplazarse al punto indicado. Pulsar 1 otra vez al terminar para que W A S D deje de controlar el joystick.

Si W no activa teleportación: abrir Project → Assets → Samples → XR Interaction Toolkit → [versión] → Starter Assets → XRI Default Input Actions y revisar los bindings de Teleport Mode Activate, Teleport Mode Cancel y Teleport Select. Utilizar en el simulador el botón o eje que figure allí.

7. Diagnóstico rápido

Los controladores no se mueven
Hacer clic en Game, confirmar que la escena está en Play Mode, seleccionar una mano con T/Y y revisar que el prefab XR Device Simulator tiene acciones asignadas.
Los controladores se mueven, pero Grip y Trigger no responden
Revisar XR Origin (XR Rig) → Input Action Manager → Action Assets → XRI Default Input Actions. Comprobar también en los controladores que las referencias de Select y Activate no estén vacías.
El objeto no se puede agarrar con Direct Interactor
Verificar Collider, Rigidbody y XR Grab Interactable en el objeto. En el hijo Direct Interactor, comprobar XR Direct Interactor y Sphere Collider → Is Trigger = ON.
El rayo funciona, pero la teleportación no
Comprobar que se está usando Teleport Interactor, no el Ray Interactor normal; revisar la capa Teleport en ambos extremos y confirmar Teleportation Provider, Locomotion Mediator y XR Body Transformer.
WASD mueve una mano cuando quería mover el joystick
Pulsar 1 para activar Primary 2D Axis. La tecla 3 cambia el objetivo de WASD a la posición del dispositivo; revisar el estado mostrado en la interfaz del simulador.
