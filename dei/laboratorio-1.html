Laboratorio 1

Configuración del entorno y primera escena XR

Dejar un proyecto Unity totalmente configurado para desarrollo XR y con una primera escena de prueba ejecutable; opcionalmente, guardar el proyecto en GitHub.

En este primer laboratorio se prepara el entorno de desarrollo necesario para comenzar a crear experiencias inmersivas con Unity. El objetivo no es todavía diseñar una experiencia compleja, sino construir una base técnica estable que servirá para todos los laboratorios posteriores. Durante la sesión se instalará o verificará Unity Hub y Unity 6 LTS, se creará el proyecto base del curso, se configurarán los paquetes principales de XR, se añadirá un XR Origin a la escena y se preparará una primera escena de prueba con suelo, iluminación y objetos básicos. De forma opcional, se podrá conectar el proyecto con GitHub para guardar una copia en la nube y comenzar a documentar sus versiones desde el primer día.

Convención de rutas del curso

Todas las rutas parten de la raíz local del proyecto: Project → Assets → _Project. Cuando se utilicen recursos importados por un paquete, la ruta se indicará desde Project → Assets → Samples.

Conceptos clave

Unity Hub

Aplicación que permite instalar versiones de Unity, crear proyectos y gestionar módulos adicionales.

Unity 6 LTS

Versión estable de Unity recomendada para el curso. Usar una versión LTS ayuda a reducir problemas de compatibilidad durante el desarrollo.

URP

Universal Render Pipeline. Pipeline gráfico recomendado para proyectos 3D ligeros, escalables y adecuados para prototipos XR.

XR

Término general que agrupa realidad virtual, realidad aumentada y realidad mixta.

OpenXR

Estándar abierto para desarrollar aplicaciones XR compatibles con múltiples dispositivos.

XR Plug-in Management

Sistema de Unity para gestionar proveedores XR según la plataforma de destino.

XR Interaction Toolkit

Paquete de Unity que permite crear interacciones XR mediante componentes como interactores, interactuables, locomoción y UI XR.

Input System

Sistema moderno de entrada de Unity para trabajar con dispositivos, controladores, teclado, ratón y mandos XR.

XR Origin

Objeto central de una escena XR. Define la posición del usuario, la cámara y los controladores dentro del espacio virtual.

XR Device Simulator

Herramienta que permite simular un dispositivo XR desde el editor. Es útil cuando no se dispone de headset durante la práctica.

Verificación de Paquetes Iniciales (URP + Base del Curso)

Realiza esta verificación después de crear el proyecto 3D URP y antes de configurar XR. Estos tres paquetes deben quedar instalados desde Lab 1; la plantilla puede incluirlos como paquetes directos o dependencias.

PaqueteIdentificadorComprobación
Universal RPcom.unity.render-pipelines.universalBase gráfica URP del curso.
Shader Graphcom.unity.shadergraphVerificar también como dependencia de URP.
Input Systemcom.unity.inputsystemBase de entrada del curso.
  1. Abrir Window → Package Management → Package Manager → In Project. En editores con el menú anterior: Window → Package Manager.
  2. Confirmar que Universal RP, Shader Graph e Input System ya están instalados. Mostrar las dependencias en la lista si están ocultas.
  3. Si ya aparecen en In Project, no reinstalarlos. Registrar la versión existente.
  4. Si falta alguno, abrir Package Manager → Unity Registry, buscarlo por nombre o identificador y pulsar Install en la versión compatible con el editor del curso. Instalar primero Universal RP si falta y volver a comprobar Shader Graph antes de añadirlo por separado.
  5. Volver a In Project, comprobar los tres paquetes y esperar a que termine la compilación. Guardar una captura con sus versiones. No continuar con errores de resolución de paquetes.

Preparación del Proyecto para XR (OpenXR + Interacción)

Este curso prepara XR en Lab 1. Completa este bloque tras verificar los paquetes iniciales y antes de añadir XR Origin.

PaqueteIdentificadorComprobación
XR Plug-in Managementcom.unity.xr.managementInstalar solo si falta.
OpenXR Plugincom.unity.xr.openxrInstalar solo si falta.
XR Interaction Toolkitcom.unity.xr.interaction.toolkitInstalar solo si falta.
Input Systemcom.unity.inputsystemVerificar la instalación realizada al inicio.
  1. Revisar primero In Project. Si un paquete ya está presente y es compatible, no es necesario reinstalarlo.
  2. Abrir Package Manager → Unity Registry. Instalar los tres paquetes XR que no estén presentes: XR Plug-in Management, OpenXR Plugin y XR Interaction Toolkit. Usar las versiones estables compatibles acordadas para el curso.
  3. Volver a In Project y verificar que aparecen los tres paquetes XR y también Input System. Si falta Input System, instalarlo desde Unity Registry; XRI normalmente lo incorpora como dependencia.
  4. Distinguir instalación de activación: en Edit → Project Settings → XR Plug-in Management, activar OpenXR para el destino VR utilizado (PC y/o Android para visor). Revisar Project Validation y resolver sus incidencias según la plataforma.
  5. En Player → Active Input Handling, activar Input System Package (New); guardar y reiniciar si Unity lo solicita. Importar Starter Assets y el simulador desde Samples de XRI solo si todavía no se han importado.
  6. Registrar los paquetes y versiones. Si se actualiza XRI por una incompatibilidad, revisar sus Samples y acciones de entrada antes de continuar.

Quest autónomo, sin PC VR

Play no envía automáticamente la escena al visor. Se necesita una build Android: activar el modo desarrollador del visor, conectar por USB y autorizar la depuración. Con Android Build Support instalado desde Unity Hub, usar File → Build Profiles → Android → Switch Platform; en Scene List → Add Open Scenes, añadir Test_XR_01. Mantener el simulador desactivado en esa build.

Lista de comprobación final

























Errores comunes

No aparece XR Plug-in Management

El paquete no está instalado.

Solución

Instalarlo desde Project Settings o desde Package Manager.

OpenXR muestra advertencias

La configuración del proyecto está incompleta.

Solución

Abrir Project Validation y aplicar Fix o Fix All, si procede.

Starter Assets no aparecen

Los samples del XR Interaction Toolkit no se han importado.

Solución

Revisar Package Manager > XR Interaction Toolkit > Samples e importar Starter Assets.

El proyecto pide reiniciar Unity

Se ha activado Input System.

Solución

Guardar cambios y reiniciar Unity. Esto es normal al cambiar el sistema de entrada.

Hay dos cámaras en la escena

Se mantiene la Main Camera original y además se ha añadido XR Origin.

Solución

Eliminar Main Camera si XR Origin ya incluye cámara.

XR Device Simulator no responde

No se importó el sample, Input System no está activo, faltan acciones de input o la escena no tiene XR Origin correctamente configurado.

Solución

Revisar que XR Device Simulator está importado y que Input System está activo.

Git añade demasiados archivos

Falta un .gitignore adecuado para Unity.

Solución

Revisar que el .gitignore excluye al menos: Library, Temp, Obj, Build, Builds, Logs y UserSettings.
