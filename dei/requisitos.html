Introducción · Preparación del curso

Requisitos técnicos del curso

Comprueba estas cuentas, aplicaciones y recursos antes de comenzar los laboratorios con Unity.

Cuentas necesarias

Necesaria

Cuenta de Unity Hub

Se utiliza una cuenta de Unity para iniciar sesión en Unity Hub, instalar Unity 6 LTS, gestionar módulos y crear o abrir el proyecto del curso.

Opcional · muy recomendable

Cuenta de GitHub

No es obligatoria para completar el curso. Se recomienda para guardar una copia del proyecto en la nube, mantener un historial de versiones y facilitar su recuperación.

Equipo y software







GitHub no es obligatorio

Si no se utiliza GitHub, el proyecto puede guardarse únicamente en el equipo. En ese caso, conviene mantener una copia de seguridad local en otra unidad. La conexión con GitHub se ofrece como ampliación opcional en el Laboratorio 1.
